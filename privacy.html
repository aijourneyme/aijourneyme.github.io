개인정보처리방침 · Privacy Policy

시행일 · Effective date: 2026-10-06

1. 이 앱이 하는 일 · What the app does

moneystep-publisher(이하 "앱")는 돈공부 첫걸음 채널 운영자가 본인 컴퓨터에서 실행하는 개인용 도구로, 운영자가 만든 영상·제목·설명·썸네일을 운영자 본인의 YouTube 채널과 Instagram 계정에 업로드하고 예약 게시해요.

moneystep-publisher ("the app") is a personal tool run by the owner of the 돈공부 첫걸음 channel on the owner's own computer. It uploads and schedules the owner's own videos, titles, descriptions and thumbnails to the owner's own YouTube channel and Instagram account.

2. YouTube API 서비스 사용 · Use of YouTube API Services

이 앱은 YouTube API 서비스를 사용해요. 이 앱을 사용하면 YouTube 서비스 약관에 동의하는 것이며, Google의 개인정보 처리는 Google 개인정보처리방침을 따라요.

This app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

3. 접근하는 정보 · Information accessed

  • 운영자 본인 YouTube 채널의 기본 정보(채널 ID, 이름, 업로드 목록)와 업로드·예약·썸네일 설정·예약 상태 확인에 필요한 영상 정보
  • 운영자 본인 Instagram 프로페셔널 계정의 기본 정보(사용자 ID, 사용자명)와 게시에 필요한 정보

Basic information about the owner's YouTube channel (channel ID, name, uploads list) and the video data needed to upload, schedule, set thumbnails and check scheduled status; basic information about the owner's Instagram professional account (user ID, username) needed to publish. The app does not access, collect or process data about viewers or any other users.

4. 저장 방법 · How information is stored

로그인 토큰은 운영자 컴퓨터의 macOS 키체인(Keychain)에만 암호화되어 저장되고, 게시 기록(영상 ID, 링크, 예약 시각)은 운영자 컴퓨터의 로컬 파일에만 저장돼요. 별도 서버로 보내거나 제3자와 공유·판매하지 않아요. 게시물에 필요한 영상 파일은 업로드 처리 동안에만 임시 주소로 플랫폼에 전달되고 게시 후 바로 닫혀요.

Access tokens are stored only in the macOS Keychain on the owner's computer. Publishing records (video IDs, links, scheduled times) are stored only in local files on that computer. No data is sent to any other server, and no data is shared with or sold to third parties. Media files are made available to the platform through a temporary link only while an upload is being processed, then the link is closed.

5. Google 사용자 데이터 · Google user data (Limited Use)

moneystep-publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the publishing features described above and is not used for advertising or transferred to anyone else.

6. 보관 및 삭제 · Retention and deletion

토큰과 기록은 운영자가 연결을 해제하거나 앱을 삭제할 때까지 보관되고, 언제든 로컬에서 삭제할 수 있어요. Google 계정의 접근 권한은 Google 계정 권한 페이지에서, Instagram은 앱 설정의 "앱 및 웹사이트"에서 언제든 해제할 수 있어요.

Tokens and records are kept until the owner disconnects the account or removes the app, and can be deleted locally at any time. Access can be revoked at any time on the Google Account permissions page (and for Instagram under Settings → Apps and websites).
